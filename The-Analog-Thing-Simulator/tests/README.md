# Tests

Run from the bundle root:

```bash
node tests/run_tests.js
```

The test runner uses only Node.js built-in modules. It covers component behavior, patch validation, operation modes, serialized patch loading/saving, damped-oscillation traces, browser-helper functions, browser patch editing, the v009 serialized example gallery, the v010 browser serialized-patch runtime, v011 reusable templates, v012 SVG cable interaction helpers, v021 custom-design JSON round trips, and v022 physical socket map validation.
