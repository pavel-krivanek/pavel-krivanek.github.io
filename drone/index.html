Standard roots use A4 = 440 Hz in equal temperament, then just-intonation ratios for the other degrees. These common 5-limit scales are one of several possible natural-tuning conventions. The 3-second reference capture and live tuner are separate microphone modes; the live tuner does not save audio. Use headphones while running the drone and tuner together so the microphone does not detect the drone from your speakers. Microphone access requires HTTPS, localhost, or a browser that permits local HTML files.
